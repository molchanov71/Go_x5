# Анализатор продаж

## Структуры:
```go
type Sale struct {
  Product          string // товар
  Category         string // категория
  Quantity         int    // количество единиц
  UnitPriceKopecks int64  // цена одного товара в копейках
  Cancelled        bool   // отменена ли продажа
}

type Report struct {
  RevenueKopecks    int64            // выручка в копейках
  UnitsSold         int              // количество проданных единиц
  RevenueByCategory map[string]int64 // словарь, в котором ключ - категория, значение - выручка по данной категории
  TopProduct        string           // самый продаваемый товар по количеству единиц
  InvalidSales      int              // число некорректных записей
}
```
## Описание алгоритма
Функция ```AnalyzeSales``` линейно проходит по срезу продаж, пропускает отменённые продажи, добавляет некорректные записи, заполняет остальные поля отчёта, кроме TopProduct, который рассчитывается в конце. В это поле выбирается ключ, соответствующий наибольшему значению словаря ```quantities```.

## Сложности
Временная сложность - ```O(n + k)```, где ```n``` - число продаж, ```k``` - число уникальных товаров; пространственная - ```O(n + k + p)```, где ```n``` - число продаж, ```k``` - число уникальных товаров, ```p``` - число уникальных категорий.
