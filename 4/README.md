## Назначение пакетов
- ```config``` - добавляет в программу переменные среды выполнения
- ```handler``` - хранит в себе один сервис (интерфейс ```creator```) и выполняет метод ```Create``` через этот интерфейс
- ```service``` - реализует структуру ```Service``` и её метод ```Create```
- ```repository``` - реализует хранение и доступ к заказам в репозитории
- ```model``` - описывает структуру одного заказа (```order```)
